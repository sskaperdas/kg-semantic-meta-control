# Evidence-Gated Semantic Meta-Control (EGSMC)

> **Αυτό είναι το αμέσως επόμενο βήμα.**
>
> Δεν αλλάζουμε τώρα το training, τα Top-K predictions, το υπάρχον checker, το reranking ή τα metrics.
>
> Ο στόχος είναι να μετατρέψουμε το απλό:
>
> ```text
> VALID / INVALID / UNKNOWN
> ```
>
> σε **ρητό evidence record** που εξηγεί *γιατί* ένας candidate έχει ή δεν έχει semantic/structural support.

---

# 1. Πού βρισκόμαστε ήδη

Έχουν ήδη ολοκληρωθεί:

```text
Top-K reader
semantic resources
semantic checker
candidate annotation
simple VALID-first reranking
baseline-vs-controlled evaluation
```

Το DrugBank sanity report που έχει παραχθεί δείχνει:

```text
checked: 15124
VALID:   15124
INVALID: 0
UNKNOWN: 0
```

Άρα ο βασικός checker είναι συνεπής με τα πραγματικά DrugBank test triples.

Στο `DRUGBANK / ROTATE / test tail`, το υπάρχον απλό reranking έδωσε ήδη:

```text
MRR@50:
0.4831 -> 0.4904

Hits@1:
0.3514 -> 0.3567

Hits@10:
0.7534 -> 0.7599

Valid@1:
0.9530 -> 0.9999

Candidate Valid Rate@10:
0.9011 -> 0.9601
```

Αυτό είναι χρήσιμο ως **simple semantic reranking baseline**.

Όμως δεν είναι ακόμη πλήρες EGSMC.

Γιατί;

Επειδή η τωρινή απόφαση βασίζεται ουσιαστικά στο:

```text
VALID
UNKNOWN
INVALID
```

και όχι στο:

```text
πόσο evidence υπάρχει;
από πού προέρχεται;
είναι άμεσο ή μέσω hierarchy;
υπάρχει explicit conflict;
υπάρχει structural support στο graph;
```

Αυτό ακριβώς προσθέτουμε τώρα.

---

# 2. Τι σημαίνει «evidence» σε αυτή την εργασία

Για κάθε candidate triple:

```text
(h, r, t)
```

θέλουμε να κρατάμε ξεχωριστά **τι στοιχεία το υποστηρίζουν ή το αντικρούουν**.

Η λογική του επόμενου βήματος είναι:

```text
candidate
   ↓
┌────────────────────────────────┐
│ ONTOLOGY / SCHEMA EVIDENCE     │
│                                │
│ direct type support            │
│ hierarchy support              │
│ domain/range compatibility     │
│ disjointness conflict          │
└────────────────────────────────┘
   +
┌────────────────────────────────┐
│ GRAPH EVIDENCE                 │
│                                │
│ direct structural connection   │
│ short witness path             │
└────────────────────────────────┘
   ↓
explicit evidence record
```

Σε **αυτό** το βήμα δεν αποφασίζουμε ακόμη:

```text
evidence score
threshold
gate
final reranking
abstention
```

Πρώτα καταγράφουμε σωστά τα raw evidence signals.

# 3. Πολύ σημαντικό: από εδώ και πέρα δουλεύουμε πρώτα στο validation

Τα προηγούμενα test αποτελέσματα είναι χρήσιμα ως sanity/baseline results.

Από εδώ και πέρα όμως, όταν σχεδιάζουμε evidence rules, weights ή thresholds, δεν πρέπει να τα επιλέγουμε κοιτάζοντας το test set.

Άρα το πρώτο evidence input θα είναι:

```text

```

και το graph evidence θα χρησιμοποιεί **μόνο**:

```text
data/processed/drugbank_core/train.tsv
```

Δεν χρησιμοποιούμε:

```text
valid.tsv
test.tsv
is_gold
gold_rank_in_export
```

για να κατασκευάσουμε evidence.

Τα `is_gold` / `gold_rank_in_export` παραμένουν μόνο για evaluation.

# 4. Πρώτο evidence component — direct type support

Έστω:

```text
candidate triple:
(drug:DB00001, has_target, target:BE0000048)
```

και:

```text
head direct type = Drug
tail direct type = Target

has_target:
domain = Drug
range  = Target
```

Τότε έχουμε:

```text
domain direct support = YES
range direct support  = YES
```

Αυτό είναι το ισχυρότερο και πιο απλό ontology evidence:

> ο δηλωμένος τύπος του entity ταιριάζει απευθείας με το type που περιμένει η relation.

---

# 5. Δεύτερο evidence component — hierarchy support

Μπορεί να μην υπάρχει direct match.

Παράδειγμα:

```text
entity type = GlossaryArticle
expected range = Content
```

και στο hierarchy:

```text
GlossaryArticle -> Content
```

Τότε:

```text
direct match    = NO
expanded match  = YES
```

Άρα το candidate έχει:

```text
HIERARCHY_SUPPORT
```

---

# 6. Τρίτο evidence component — disjointness conflict

Το disjointness πρέπει να χρησιμοποιηθεί πολύ συγκεκριμένα.

Παράδειγμα:

```text
relation range expects: Target
candidate direct type:  Category
```

και:

```text
Category disjoint Target
```

Τότε έχουμε ισχυρό negative evidence:

```text
DISJOINT_CONFLICT
```

## Προσοχή

Δεν ελέγχουμε αν:

```text
head type
```

είναι disjoint με:

```text
tail type
```

Το:

```text
Drug --has_target--> Target
```

δεν είναι invalid επειδή `Drug` και `Target` είναι διαφορετικές/disjoint classes.

Ελέγχουμε:

```text
actual head type      VS expected domain
actual candidate type VS expected range
```

---

# 7. Τέταρτο evidence component — graph evidence

Το ontology/schema μπορεί να μην έχει όλη την πληροφορία.

Γι' αυτό προσθέτουμε structural evidence από το training graph.

Για ένα candidate:

```text
(h, r, t)
```

ρωτάμε:

```text
Υπάρχει ήδη κάποια σύντομη structural σύνδεση
μεταξύ h και t στο training graph;
```

Στην πρώτη έκδοση θα κρατήσουμε μόνο δύο απλά signals:

```text
1-hop structural witness
2-hop structural witness
```

## 1-hop

Υπάρχει κάποια άλλη γνωστή edge σύνδεση μεταξύ `h` και `t`.

## 2-hop

Υπάρχει entity `x` ώστε:

```text
h --...--> x --...--> t
```

ή η αντίστοιχη αντίστροφη κατεύθυνση.

## Τι ΔΕΝ ισχυριζόμαστε

Ένα 2-hop path δεν αποδεικνύει ότι το candidate triple είναι factually true.

Το χρησιμοποιούμε μόνο ως:

```text
structural support signal
```

```python
from __future__ import annotations

from collections import defaultdict
from pathlib import Path

from kgsmc.semantic_control.checker import SemanticChecker
from kgsmc.semantic_control.resources import SemanticResources


class GraphEvidenceIndex:
    # Απλό structural index του TRAIN graph.
    # adjacency[u][v] = set of relation labels

    def __init__(self, train_file: str | Path):
        self.train_file = Path(train_file)

        self.adjacency: dict[str, dict[str, set[str]]] = defaultdict(
            lambda: defaultdict(set)
        )

        self._load()

    def _load(self) -> None:
        if not self.train_file.exists():
            raise FileNotFoundError(self.train_file)

        with self.train_file.open(
            "r",
            encoding="utf-8",
        ) as file:

            for line_number, line in enumerate(
                file,
                start=1,
            ):
                line = line.rstrip("\r\n")

                if not line:
                    continue

                parts = line.split("\t")

                if len(parts) != 3:
                    raise ValueError(
                        f"Invalid triple at "
                        f"{self.train_file}:{line_number}"
                    )

                head, relation, tail = parts

                # Original direction
                self.adjacency[head][tail].add(
                    relation
                )

                # Reverse traversal.
                # ^relation σημαίνει traversal ανάποδα.
                self.adjacency[tail][head].add(
                    "^" + relation
                )

    def _relation_for_edge(
        self,
        source: str,
        target: str,
    ) -> str | None:
        relations = self.adjacency.get(
            source,
            {},
        ).get(
            target,
            set(),
        )

        if not relations:
            return None

        return sorted(relations)[0]

    def find_short_witness(
        self,
        head: str,
        relation: str,
        tail: str,
    ) -> dict:
        # Βρίσκει structural witness μήκους 1 ή 2.
        # Δεν χρησιμοποιεί το ίδιο candidate relation
        # ως direct evidence για το ίδιο triple.

        head_neighbors = self.adjacency.get(
            head,
            {}
        )

        # 1-hop witness
        if tail in head_neighbors:
            available_relations = [
                edge_relation
                for edge_relation in sorted(
                    head_neighbors[tail]
                )
                if edge_relation not in {
                    relation,
                    "^" + relation,
                }
            ]

            if available_relations:
                witness_relation = (
                    available_relations[0]
                )

                return {
                    "has_structural_support": True,
                    "shortest_witness_length": 1,
                    "witness_path": [
                        head,
                        witness_relation,
                        tail,
                    ],
                }

        # 2-hop witness
        tail_neighbors = self.adjacency.get(
            tail,
            {}
        )

        common_neighbors = (
            set(head_neighbors)
            & set(tail_neighbors)
        )

        if common_neighbors:
            # Deterministic choice
            middle = sorted(common_neighbors)[0]

            first_relation = self._relation_for_edge(
                head,
                middle,
            )

            second_relation = self._relation_for_edge(
                middle,
                tail,
            )

            if (
                first_relation is not None
                and second_relation is not None
            ):
                return {
                    "has_structural_support": True,
                    "shortest_witness_length": 2,
                    "witness_path": [
                        head,
                        first_relation,
                        middle,
                        second_relation,
                        tail,
                    ],
                }

        return {
            "has_structural_support": False,
            "shortest_witness_length": None,
            "witness_path": None,
        }


class EvidenceExtractor:
    def __init__(
        self,
        resources: SemanticResources,
        checker: SemanticChecker,
        graph_index: GraphEvidenceIndex,
    ):
        self.resources = resources
        self.checker = checker
        self.graph_index = graph_index

    def _type_evidence(
        self,
        entity: str,
        expected_types: frozenset[str],
    ) -> dict:

        direct_types = self.resources.direct_types(
            entity
        )

        expanded_types = self.resources.expanded_types(
            entity
        )

        direct_match = bool(
            direct_types & expected_types
        )

        expanded_match = bool(
            expanded_types & expected_types
        )

        hierarchy_match = (
            expanded_match
            and not direct_match
        )

        conflicts: list[str] = []

        for actual_type in sorted(direct_types):
            for expected_type in sorted(
                expected_types
            ):
                if self.resources.are_disjoint(
                    actual_type,
                    expected_type,
                ):
                    conflicts.append(
                        f"{actual_type} disjoint "
                        f"{expected_type}"
                    )

        if not expected_types:
            status = "NO_CONSTRAINT"

        elif not direct_types:
            status = "MISSING_TYPE"

        elif direct_match and conflicts:
            status = "MIXED"

        elif hierarchy_match and conflicts:
            status = "MIXED"

        elif direct_match:
            status = "DIRECT_SUPPORT"

        elif hierarchy_match:
            status = "HIERARCHY_SUPPORT"

        elif conflicts:
            status = "DISJOINT_CONFLICT"

        else:
            status = "MISMATCH"

        return {
            "status": status,
            "direct_types": sorted(direct_types),
            "expanded_types": sorted(
                expanded_types
            ),
            "expected": sorted(expected_types),
            "direct_match": direct_match,
            "hierarchy_match": hierarchy_match,
            "disjoint_conflicts": conflicts,
        }

    def extract(
        self,
        head: str,
        relation: str,
        tail: str,
    ) -> dict:

        semantic_result = (
            self.checker.check_triple(
                head,
                relation,
                tail,
            )
        )

        constraint = self.resources.constraint(
            relation
        )

        if constraint is None:
            expected_domain = frozenset()
            expected_range = frozenset()

        else:
            expected_domain = constraint.domain
            expected_range = constraint.range

        domain_evidence = self._type_evidence(
            head,
            expected_domain,
        )

        range_evidence = self._type_evidence(
            tail,
            expected_range,
        )

        graph_evidence = (
            self.graph_index.find_short_witness(
                head,
                relation,
                tail,
            )
        )

        return {
            "semantic_status": (
                semantic_result.status
            ),
            "ontology": {
                "domain": domain_evidence,
                "range": range_evidence,
            },
            "graph": graph_evidence,
        }


def add_evidence_to_record(
    record: dict,
    extractor: EvidenceExtractor,
) -> dict:

    query = record["query"]
    query_type = record["query_type"]

    for candidate in record["candidates"]:

        if query_type == "tail_prediction":
            head = query["head"]
            relation = query["relation"]
            tail = candidate["entity"]

        elif query_type == "head_prediction":
            head = candidate["entity"]
            relation = query["relation"]
            tail = query["tail"]

        else:
            raise ValueError(
                f"Unsupported query type: "
                f"{query_type}"
            )

        candidate["evidence"] = (
            extractor.extract(
                head=head,
                relation=relation,
                tail=tail,
            )
        )

    return record
```

# 11. Νέο script: `06_extract_evidence.py`

Δημιούργησε:

```text
scripts/06_extract_evidence.py
```

```python
from __future__ import annotations

import argparse
import gzip
import json
from collections import Counter
from pathlib import Path

from tqdm.auto import tqdm

from kgsmc.semantic_control.candidate_io import (
    iter_candidate_records,
)
from kgsmc.semantic_control.checker import (
    SemanticChecker,
)
from kgsmc.semantic_control.evidence import (
    EvidenceExtractor,
    GraphEvidenceIndex,
    add_evidence_to_record,
)
from kgsmc.semantic_control.resources import (
    SemanticResources,
)


def main() -> int:
    parser = argparse.ArgumentParser()

    parser.add_argument(
        "--dataset-dir",
        type=Path,
        default=Path(
            "data/processed/drugbank_core"
        ),
    )

    parser.add_argument(
        "--train-file",
        type=Path,
        default=Path(
            "data/processed/drugbank_core/train.tsv"
        ),
    )

    parser.add_argument(
        "--input-file",
        type=Path,
        default=Path(
            "03_TOPK_RESULTS/"
            "DRUGBANK/"
            "ROTATE/"
            "valid_tail_top50.jsonl.gz"
        ),
    )

    parser.add_argument(
        "--output-file",
        type=Path,
        default=Path(
            "runs/evidence/"
            "drugbank_rotate_"
            "valid_tail_top50_evidence.jsonl.gz"
        ),
    )

    parser.add_argument(
        "--summary-file",
        type=Path,
        default=Path(
            "runs/evidence/"
            "drugbank_rotate_"
            "valid_tail_evidence_summary.json"
        ),
    )

    parser.add_argument(
        "--limit",
        type=int,
        default=None,
    )

    args = parser.parse_args()

    resources = SemanticResources(
        args.dataset_dir
    )

    checker = SemanticChecker(
        resources
    )

    print("Building training graph index...")

    graph_index = GraphEvidenceIndex(
        args.train_file
    )

    extractor = EvidenceExtractor(
        resources=resources,
        checker=checker,
        graph_index=graph_index,
    )

    args.output_file.parent.mkdir(
        parents=True,
        exist_ok=True,
    )

    args.summary_file.parent.mkdir(
        parents=True,
        exist_ok=True,
    )

    query_count = 0
    candidate_count = 0

    semantic_statuses = Counter()
    domain_statuses = Counter()
    range_statuses = Counter()
    graph_lengths = Counter()

    with gzip.open(
        args.output_file,
        "wt",
        encoding="utf-8",
    ) as writer:

        for record in tqdm(
            iter_candidate_records(
                args.input_file
            ),
            desc="Extracting evidence",
            unit="query",
        ):
            record = add_evidence_to_record(
                record,
                extractor,
            )

            query_count += 1

            for candidate in record["candidates"]:
                candidate_count += 1

                evidence = candidate["evidence"]

                semantic_statuses[
                    evidence["semantic_status"]
                ] += 1

                domain_statuses[
                    evidence["ontology"]
                    ["domain"]
                    ["status"]
                ] += 1

                range_statuses[
                    evidence["ontology"]
                    ["range"]
                    ["status"]
                ] += 1

                length = (
                    evidence["graph"]
                    ["shortest_witness_length"]
                )

                if length is None:
                    graph_lengths["NONE"] += 1
                else:
                    graph_lengths[str(length)] += 1

            writer.write(
                json.dumps(
                    record,
                    ensure_ascii=False,
                    separators=(",", ":"),
                )
                + "\n"
            )

            if (
                args.limit is not None
                and query_count >= args.limit
            ):
                break

    summary = {
        "queries": query_count,
        "candidates": candidate_count,
        "semantic_statuses": dict(
            semantic_statuses
        ),
        "domain_evidence": dict(
            domain_statuses
        ),
        "range_evidence": dict(
            range_statuses
        ),
        "graph_witness_length": dict(
            graph_lengths
        ),
    }

    args.summary_file.write_text(
        json.dumps(
            summary,
            indent=2,
            ensure_ascii=False,
        ),
        encoding="utf-8",
    )

    print(
        json.dumps(
            summary,
            indent=2,
            ensure_ascii=False,
        )
    )

    print(
        f"Evidence file: {args.output_file}"
    )

    print(
        f"Summary: {args.summary_file}"
    )

    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

# 17. Γιατί σταματάμε εδώ

Μετά από αυτό το βήμα θα ξέρουμε πραγματικά:

```text
πόσο συχνό είναι direct ontology support;
πόσο συχνό είναι hierarchy-only support;
πόσα explicit conflicts υπάρχουν;
πόσο συχνά υπάρχει short graph witness;
```
